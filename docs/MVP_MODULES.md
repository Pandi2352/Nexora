# Nexora OS — MVP Modules

## Foundation

1. Authentication
   - Register, login, logout
   - Email verification
   - Forgot / reset password
   - Refresh session
2. Users & Profile
   - Profile, change password
3. Organizations
   - Create workspace, switch workspace
   - Organization settings
4. Members & Invitations
   - Invite, accept, remove, change role
5. Teams
   - Create team, assign members
6. Roles & Permissions
   - Predefined roles, permission checks

## Core

7. Dashboard
   - Metrics, summaries, overdue work, recent activity
8. CRM
   - Companies, contacts, leads, opportunities, activities
9. Projects
   - Projects, project members
10. Tasks
    - Tasks, subtasks, list + Kanban, comments, labels
11. Documents
    - Folders, upload, download, access control
12. Support
    - Tickets, assign, replies, internal notes, resolution

## Operations

13. Notifications
    - In-app, read / unread, mark all read
14. Activity & Audit
    - Activity feed, audit log
15. Search & Filters
    - Module-level search, filter, sort, pagination
16. Reports
    - Sales, work, support summaries, CSV export
17. Settings
    - General, members, teams, roles, security

## Platform

18. Platform Admin
    - Organizations, users, audit, health
19. Health
    - Liveness, readiness
